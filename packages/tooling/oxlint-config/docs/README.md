# oxlint-config

Published as `@buildkitgg/oxlint-config`. The root `vite.config.ts` extends `src/base.ts`, so add a rule there to apply
it across the repository. Base includes the recommended rule set from
[`@buildkitgg/oxlint-plugin-anti-slop`](../../oxlint-plugin-anti-slop/docs/README.md). Run root `pnpm verify` after
changes.
